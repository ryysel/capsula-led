# capsula-led — часы на кольце VK Капсулы 2019

Небольшой демон для взломанной VK Капсулы 2019 (Rockchip RK3308, Buildroot).
Пока Маруся молчит, кольцо показывает время. Как только колонка начинает
слушать, говорить или проигрывать анимацию, демон полностью уступает кольцо
штатному `voice-agent` и возвращает часы примерно через секунду после ответа.

```
              ● 12
          ●           ●
      ●       ▓ ▓        ●        ▓  заливка минут: бирюза → синий,
    ● 9      ▓  ●  ▓      3 ●         по часовой стрелке от 12
      ●       ▓ ▓        ●        ●  янтарная метка текущего часа
          ●           ●           ▲  сверху: синий = AM, янтарь = PM
              ● 6
```

Кольцо не отдаётся «силой»: демон читает машину состояний, которую
`voice-agent` пишет в syslog, и рисует только в паузах. Никаких патчей
прошивки, все файлы лежат в оверлее и убираются одной командой.

## Что показывает

- **Заливка минут** — кольцо заполняется по часовой стрелке от 12 часов по
  мере текущего часа: 12 сегментов по 5 минут, у ведущего сегмента есть
  дробная яркость. Градиент от бирюзового к синему.
- **Метка часа** — янтарный сегмент на позиции текущего часа. Рисуется поверх
  заливки, поэтому час видно всегда.
- **Верхний индикатор** — холодный синий для AM, тёплый янтарный для PM.

Кадр перерисовывается раз в 5 секунд: сегментов всего 12, чаще незачем.

## Требования

- VK Капсула 2019 с root и ADB (jailbreak). Другие колонки VK этот код не
  поддерживает: у них другая карта каналов.
- `aarch64-linux-gnu-gcc` для сборки (или готовый бинарник из релизов).
- Устройство: `/dev/led_multi_ctrl`, `logread`, `start-stop-daemon`,
  `pgrep`, `killall` — всё это в стоковой прошивке есть.

## Установка

Коротко (подробный гайд — в [docs/DEPLOY.md](docs/DEPLOY.md)):

```sh
git clone https://github.com/ryysel/capsula-led.git
cd capsula-led
./build.sh                      # или скачать готовый capsula-led из релизов
adb push capsula-led        /data/local/tmp/capsula-led
adb push etc/S98capsula-led /data/local/tmp/S98capsula-led
adb push install.sh         /data/local/tmp/install.sh
adb shell sh /data/local/tmp/install.sh /data/local/tmp/capsula-led
```

Установщик кладёт бинарник и init-скрипт в оверлей
(`/data/overlay/upper`), добавляет автозапуск в копию обёртки
`voice-agent.sh` и запускает демон. Часы появляются сразу, автозапуск
проверяется перезагрузкой.

## Как это работает

Подробности и отладочные команды — в [docs/DEPLOY.md](docs/DEPLOY.md).
Коротко:

1. Демон раз в секунду читает `logread` и ищет **последнюю** строку-маркер
   состояния (`=> PHRASE_IN_PROGRESS`, `SPEECH: start`,
   `led animation loaded …`, `onSpeechPlaybackFinished` и т. п.).
2. Если последний маркер «занято» — демон не трогает кольцо вообще.
3. Если «свободно» — рисует кадр часов раз в 5 секунд. Возврат после ответа
   идёт через 1 секунду, чтобы не спорить с финальной анимацией.
4. Если «занято» висит 40 секунд без новых строк (музыка, зацикленная
   анимация), срабатывает предохранитель и часы возвращаются.

Порядок строк берётся из буфера журнала, а не из меток времени: часы на
устройстве прыгают из-за `ntpd`, и сортировка по времени отбрасывала бы
свежие события.

## Яркость

Датчика освещённости на этой ревизии нет (подробности в гайде), поэтому
яркость по расписанию:

| Время | Яркость |
|---|---|
| 08:00–20:00 | 100 % |
| 20:00–23:00 | 70 % |
| 23:00–08:00 | 30 % |

## Команды

```sh
capsula-led clock [SEC]      # рисовать часы SEC секунд (по умолчанию 60)
capsula-led daemon           # режим демона (его и запускает init-скрипт)
capsula-led off              # погасить всё
capsula-led fill R G B       # залить кольцо одним цветом
capsula-led pixel N R G B    # один пиксель кольца (0..11)
capsula-led top R G B        # верхний индикатор
capsula-led ch N V           # произвольный канал 0..38
capsula-led test             # перебрать все сегменты по очереди
capsula-led map              # сверить карту каналов с /sys/class/leds
capsula-led watch [SEC]      # показать, меняет ли кто-то кольцо
```

Управление службой:

```sh
/etc/init.d/S98capsula-led start    # start|stop|restart
logread | grep capsula-led          # переходы clock/stock
```

## Ограничения

- Музыка и зацикленные анимации, которые не пишут финальную строку в журнал,
  держат кольцо до 40-секундного таймаута.
- Если `voice-agent` перестанет писать маркеры в syslog, определение простоя
  сломается: другого надёжного сигнала на этой прошивке нет.
- Автояркость по датчику невозможна: BH1750 читается как 0 в освещённой
  комнате, второй датчик не отвечает.

## Откат

```sh
adb shell sh /tmp/uninstall.sh   # остановит демон и уберёт файлы из оверлея
```

Либо вручную: удалить `/data/overlay/upper/usr/bin/capsula-led`,
`/data/overlay/upper/etc/init.d/S98capsula-led` и строку автозапуска из
`/data/overlay/upper/usr/bin/voice-agent.sh`, затем перезагрузить колонку.

## Сборка

```sh
./build.sh
# то же самое:
aarch64-linux-gnu-gcc -O2 -static -o capsula-led src/ledctl.c
```

Статическая сборка не зависит от glibc на устройстве. Если кросс-компилятора
нет, подойдёт контейнер:

```sh
docker run --rm -v "$PWD":/w -w /w debian:bullseye \
  bash -c 'apt-get update && apt-get install -y gcc-aarch64-linux-gnu && ./build.sh'
```
